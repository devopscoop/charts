# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it
privately **before** filing a public issue.

**Do not create a public GitHub/GitLab/Codeberg issue for security
vulnerabilities.**

Instead, send a detailed report to the maintainers via one of these channels:

- **Email**: See the repository's commit history or the `devops.coop` domain
  for maintainer contact information.
- **GitHub**: Use the **Report a vulnerability** button on the repository's
  Security tab (if enabled).

We will acknowledge receipt within 48 hours and provide an estimated timeline
for a fix. Once the vulnerability is resolved, we will coordinate disclosure
with you.

## Supported Versions

Only the latest release of each chart receives security patches. You can find
the latest release under the Releases page on GitHub, GitLab, or Codeberg.
Older versions must be updated to a supported release before a fix can be
applied.
